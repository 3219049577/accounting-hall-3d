# 从算盘到云账本 · 会计工具演进主题 3D 虚拟展厅（演进厅）

AI 辅助搭建的个人专业主题 3D 虚拟展厅。技术栈：React 19 + TypeScript + Vite + Three.js + React Three Fiber + Drei + Zustand。
全部展品模型、屏幕画面与铭牌均由程序化几何体 / Canvas 纹理生成，不依赖任何外部模型、字体或图片资源，离线可运行。

## 启动说明

环境要求：Node.js >= 18（推荐 20/22），npm >= 9；桌面 Chrome 或 Edge。

```bash
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5173 ，点击「进入展厅」开始参观。

生产构建（可选）：

```bash
npm run build
npm run preview   # http://127.0.0.1:4173
```

## 操作方式

| 操作 | 功能 |
| --- | --- |
| W / A / S / D | 前后左右移动（Shift 加速） |
| 鼠标（指针锁定后） | 转动视角 |
| 按住左键拖拽（未锁定时） | 转动视角（指针锁定不可用环境的回退方案） |
| 点击展品 | 打开详情面板（锁定状态下以准星瞄准点击） |
| ESC | 释放鼠标锁定 / 关闭详情面板 |
| R 或右上角「重置位置」 | 回到入口 |
| 右侧导航 | 四个展厅入口（仅演进厅可用）+ 三个展区直达 |
| 右上角「全屏」 | 切换全屏 |

靠近展品（<3.4m）或准星/鼠标悬停时展台高亮；点击打开详情面板，关闭后恢复漫游。
墙壁、隔墙与展台均有碰撞检测，不可穿越；隔墙中央留 6m 开口形成连续参观动线：
入口 → 第一展区（算盘时代）→ 第二展区（电算化时代）→ 第三展区（云端时代）→ 尾厅主题墙。

## 展区与展品（8 件，均可交互）

- 第一展区 · 算盘时代：传统算盘、手工财务账本
- 第二展区 · 电算化时代：会计电算化计算机、ERP 财务管理系统、财务共享服务中心
- 第三展区 · 云端时代：RPA 智能财务机器人、AI 财务分析驾驶舱、云账本与区块链电子凭证

展品名称、简介、要点、来源说明与外部链接统一配置在 `src/data/exhibits.ts`，不写死在 3D 组件中。
所有模型与界面画面为教学**示意**；详情面板内逐件标注来源说明；外部资源链接未配置时显示「演示占位」。

## 项目结构

```
src/
  data/        layout.ts（空间尺寸/展区/动线） exhibits.ts（展品配置） halls.ts（展厅导航配置）
  state/       store.ts（Zustand 全局状态：锁定/面板/悬停/展区/重置/跳转）
  three/       Scene.tsx（Canvas 组装） Hall.tsx（建筑/灯光/发光线条/反射地面）
               PlayerController.tsx（第一人称移动/视角/指针锁定/拖拽回退/射线交互）
               collision.ts（AABB 碰撞系统） Exhibit.tsx（展台/铭牌/高亮/命中盒）
               models.tsx（8 件程序化展品模型） textures.ts（Canvas 纹理） DataFlow.tsx（金色数据流）
  ui/          HUD.tsx（顶栏/导航/提示/帮助/入口封面） DetailPanel.tsx（展品详情面板）
```
